# Product showcase direction

Reference review: November 14, 2026. Live pages and browser captures inspected; no third-party media or implementation code was copied into this website.

## Observations

The [Apple homepage](https://www.apple.com/) uses a narrow global navigation (44 px in the inspected desktop view), concise centered headlines, two clearly differentiated actions and a large visual focus. Broad sections alternate light and dark surfaces. Secondary showcases can share a two-column row.

The [iPhone product presentation](https://www.apple.com/iphone-18-pro/) gives the product image and benefit statement priority over technical specifications. Its additional navigation keeps the main product action available. The [Mac category page](https://www.apple.com/mac/) separates product discovery and filtering into a quieter, pale surface.

## CPSI LABS decisions

These observations informed a distinct composition: the genuine CS monogram as the brand hero, original geometric software/privacy/precision artwork, a navy full-width showcase, contrasting value sections, blue actions and deliberately brief copy. Manrope remains locally hosted; no Apple fonts, images, videos, logos or scripts are used.

White is now the default. Dark mode has its own surfaces and retains a clear stage for the original navy/blue monogram. Explicitly saved preferences remain valid. Motion consists of a finite brand entrance, once-only scroll reveals and short control feedback; reduced-motion changes cancel active reveals. Content remains visible if observation or motion is unavailable.

The software catalogue stays empty. Real product entries will activate benefits-first pages, genuine screenshots in explicitly selected device frames, compatibility details and official release downloads. Placeholder product images appear only in the isolated test fixture and are prominently marked as test material.
