# CPSI LABS

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React, TypeScript, Vite, Tailwind CSS, Lucide. Static GitHub Pages, built through GitHub Actions. Requested by the owner.

## Product Purpose

Official independent software publishing identity. Introduce the lab, its mission and technical disciplines; distribute future verified applications and their documentation.

## Capabilities and Constraints

Eight pages: home, applications, application details, downloads, documentation, about, support, legal. English default, complete French translation, persistent language and light/dark themes. Central typed catalogue. No published applications yet; no fabricated products, customers, metrics or testimonials.

## Brand Commitments

CPSI LABS. Build. Innovate. Evolve. Original CS symbol and supplied logos; navy, electric blue, white, black. Owner explicitly requests a full product-showcase redesign inspired by Apple’s simplicity and presentation quality, without copying proprietary assets. White-dominant default, alternating white / pale gray / black / navy sections, centered brand hero, large original visuals, blue actions, thin navigation, restrained scroll motion. Preserve existing explicit theme choices and English default. Direct implementation and deployment authorized.

## Evidence on Hand

Seven owner-supplied logo variations. Existing safety, licensing and FAQ content. Official GitHub https://github.com/cpsi-labs. No public email or configured support forum.

## Product Principles

Preserve the publisher's anonymity. Publish no real name, personal address, phone, keys or credentials. GitHub is the official communication channel. Label unavailable releases honestly. Make downloadable assets and their licensing traceable to official releases.

## Accessibility & Inclusion

Responsive mobile/tablet/desktop; keyboard navigation, reduced motion and readable contrast in both themes. Full English and French.
